边缘网关方案思路 (Tencent Cloud EdgeOne)

该模块作为系统的核心“云端保安”，主要承担**极速访问、合规避险、权限验证**三大职能。

### 1. 基础设施策略：借道香港，合规加速
* **选型核心**：采用腾讯云 EdgeOne 的**海外版（国际版）**。
* **路由策略**：配置加速区域为**“全球（不含中国大陆）”**。
* **核心逻辑**：
    * 利用腾讯云的智能调度算法，将中国大陆用户的请求自动路由至物理距离最近的**中国香港**或**新加坡**边缘节点。
    * **合规性**：由于服务器节点物理位置在境外，**完全无需进行 ICP 备案**，规避了业务早期的合规门槛。
    * **性能**：实现对大陆用户的毫秒级响应（30ms-50ms），解决传统海外服务器访问慢、丢包严重的问题。

### 2. 数据存储策略：全球分布式白名单 (Edge KV)
* **存储核心**：使用 **Edge KV (边缘键值存储)**。
* **核心逻辑**：
    * **副本分发**：将你的“有效卡密名单”像 CDN 缓存静态文件一样，自动复制并同步到全球每一个边缘节点。
    * **就近读取**：当用户发起验证时，边缘节点直接查询本地缓存的名单，**无需回源**到中心服务器。这意味着无论多少用户同时验证，都能瞬间返回结果，不存在数据库性能瓶颈。

### 3. 验证执行策略：无服务器拦截 (Edge Functions)
* **计算核心**：使用 **Edge Functions (边缘函数)**。
* **核心逻辑**：
    * **拦截器模式**：在用户真正连接上游 AI 接口之前，先访问这个边缘函数进行“资格审查”。
    * **查岗流程**：
        1.  函数接收用户前端提交的 Key。
        2.  函数在本地 KV 数据库中查找该 Key 是否存在。
        3.  **通过**：如果 Key 存在，立即返回“通过”信号。
        4.  **拒绝**：如果 Key 不存在，直接返回 403 禁止访问，拦截非法请求。
    * **轻量化**：该函数只做“Yes/No”的判断，不处理复杂的生图任务，也不转发大流量图片，运行成本极低。

### 总结
该方案本质上构建了一个**“离用户最近的、免备案的、只读的”**鉴权层。它将验证压力完全分散到了边缘网络，既保证了用户秒开的体验，又用最低的成本实现了对上游 API 资产的保护。
